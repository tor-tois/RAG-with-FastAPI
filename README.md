# RAG with FastAPI

A Retrieval-Augmented Generation (RAG) application built with **FastAPI, LangChain, Google Gemini, and FAISS**. This project allows users to ask questions about PDF documents and receive context-aware answers generated by Google's Gemini LLM.

## Overview

This application implements a basic RAG pipeline that retrieves relevant information from PDF documents using vector similarity search and generates answers based on the retrieved context.

Instead of relying entirely on the LLM's pre-trained knowledge, the application uses information extracted from uploaded or configured PDF documents to provide more relevant and context-specific responses.

## Features

- PDF document loading and text extraction using PyMuPDF.
- Text chunking with RecursiveCharacterTextSplitter.
- Semantic embeddings using Google Gemini Embeddings.
- Vector storage and similarity search using FAISS.
- Context-based answer generation using Gemini 2.5 Flash.
- Asynchronous retrieval and LLM invocation.
- REST API development using FastAPI.
- Docker support for containerization.

## RAG Architecture

The application follows this workflow:

```text
          PDF Document
                |
                v
          PyMuPDFLoader
                |
                v
         Text Splitting
                |
                v
       Gemini Embeddings
                |
                v
          FAISS Vector Store
                |
                v
          User Question
                |
                v
          Similarity Search
                |
                v
        Relevant Documents
                |
                v
        Context + Question
                |
                v
       Google Gemini LLM
                |
                v
          Generated Answer
                |
                v
          FastAPI Response
```

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/tor-tois/RAG-with-FastAPI.git

cd RAG-with-FastAPI
```

### 2. Create a Virtual Environment

```bash
python -m venv ragenv
```

Activate the environment on Windows:

```powershell
.\ragenv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Create a `.env` file in the project root directory.

```env
GEMINI_API_KEY=your_google_gemini_api_key
```

Get your API key from [Google AI Studio](https://aistudio.google.com/apikey).

**Important:** Never commit your actual API key or `.env` file to GitHub.

### 5. Add Your PDF Document

Place your PDF document inside the `data/` directory.

The current implementation uses:

```text
data/SAM.pdf
```

If you use a different PDF filename, update the document path in `rag.py`.

### 6. Run the Application

Start the FastAPI server:

```bash
uvicorn main:app --reload
```

The application should be available at:

```text
http://localhost:8000
```

### 7. Explore API Documentation

FastAPI provides interactive API documentation through Swagger UI.

Open:

```text
http://localhost:8000/docs
```

You can test the available API endpoints directly from your browser.

## Run with Docker

### 1. Build the Docker Image

```bash
docker build -t rag-api .
```

### 2. Create and Run the Container

```bash
docker run -d \
  -p 8000:8000 \
  --name rag-container \
  --env-file .env \
  rag-api
```

For Windows PowerShell, you can also run the command on one line:

```powershell
docker run -d -p 8000:8000 --name rag-container --env-file .env rag-api
```

### 3. Check Running Containers

```bash
docker ps
```

### 4. View Container Logs

```bash
docker logs -f rag-container
```

### 5. Stop the Container

```bash
docker stop rag-container
```

## Configuration

Current RAG configuration:

| Parameter | Value |
|---|---|
| LLM | Gemini 2.5 Flash |
| Temperature | 0.2 |
| Embedding Model | gemini-embedding-001 |
| Vector Store | FAISS |
| Search Type | Similarity |
| Retrieved Chunks (k) | 5 |
| Chunk Size | 1000 |
| Chunk Overlap | 50 |

## Limitations

- The current implementation uses a configured PDF document path.
- FAISS indexing and retrieval persistence need further implementation.
- Retrieval quality depends on document extraction, chunking, and embedding quality.
- Google Gemini API usage is subject to API quotas and rate limits.
